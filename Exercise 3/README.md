# Exercise 3 – Data Story: TV Energy Consumption

## Overview

This exercise presents a data story based on a TV energy consumption dataset. The website uses visualisations and supporting text to communicate how screen size, screen technology, and energy efficiency relate to power consumption.

The main aim of the website is to help viewers understand that larger televisions generally consume more power, but energy efficiency cannot be judged by screen size alone. Consumers should also consider screen technology, power consumption, and star rating when comparing televisions.

---

## Data Story

### Audience

The target audience for this visualisation is Australian consumers who are planning to buy a television and want to make a more informed decision about energy use.

This audience is likely to care about:

- Choosing a television that fits their viewing needs
- Understanding how screen size affects power consumption
- Comparing energy efficiency across different TV models
- Avoiding unnecessary electricity use over time

The visualisation is designed to be simple and easy to understand so that consumers can quickly identify the main patterns in the data.

### Story Overview

The data story focuses on the question:

**Do bigger televisions use more power, and does screen size determine energy efficiency?**

The website guides the viewer through the story using four main visualisations:

1. The most common TV screen technologies in the dataset
2. Average power consumption by screen technology
3. The relationship between screen size and power use
4. The relationship between star rating and screen size

The visualisations show that LCD (LED) is the most common screen technology in the dataset. The data also shows that LCD has the lowest average power consumption, while OLED has the highest average power consumption.

The screen size and power use chart shows that larger televisions, especially 65-inch and 75-inch models, generally consume more power. However, the star rating and screen size chart shows no clear relationship between screen size and star rating. This means that screen size alone does not fully determine energy efficiency.

The main recommendation is that consumers should compare screen size, power consumption, and star rating together before choosing a television.

## Storyboard

A storyboard was created to plan the user experience of the website. The storyboard follows this flow:

1. Introduce the issue of TV buyers overlooking energy consumption
2. Identify the audience as Australian consumers buying televisions
3. Show the most common screen technologies
4. Show the relationship between screen size and power consumption
5. Show the relationship between star rating and screen size
6. Provide a final recommendation for consumers

This storyboard helps structure the website as a clear data story rather than a list of separate charts.

## About the Data

### Data Source

The dataset used in this project contains information about television models available in Australia, including screen technology, screen size, brand, star rating, and power consumption.

The dataset was provided as part of the course materials for COS30045 Data Literacy with KNIME.

### Data Processing

The dataset was processed using KNIME before being used in the website. The processing included:

- Cleaning and standardising brand names
- Grouping screen sizes into categories such as 24", 32", 43", 55", 65", and 75"
- Grouping data by screen technology, screen size, and brand
- Calculating model counts for categorical comparisons
- Calculating average power consumption for screen technologies and brands
- Creating charts to support the data story

The final website uses selected visualisations from the KNIME analysis to communicate the most important findings.

### Privacy

The dataset does not contain personal or sensitive information. It focuses only on product information such as television specifications, energy ratings, and power consumption.

Because no individual people are represented in the dataset, the privacy risk is low.

### Accuracy and Limitations

The analysis is based on the dataset provided for the exercise, so the findings may not represent every television model available in Australia.

Some limitations include:

- The dataset may not include all current television models
- Some brands may appear under slightly different names
- Average values may be affected by the number of models in each group
- Real-world power consumption may vary depending on brightness settings, usage time, and viewing habits
- Screen size was grouped into categories, so the analysis shows general patterns rather than exact model-by-model comparisons

The visualisations should therefore be interpreted as general insights rather than absolute conclusions.

### Ethics

The visualisations were designed to communicate the data clearly and responsibly. The charts are supported with written explanations so that viewers understand what is being compared.

This project avoids misleading viewers by:

- Clearly explaining the purpose of each visualisation
- Avoiding exaggerated claims
- Presenting limitations of the dataset
- Making recommendations based on the patterns shown in the data

The goal is to help consumers make more informed decisions, not to promote or criticise any specific brand unfairly.
